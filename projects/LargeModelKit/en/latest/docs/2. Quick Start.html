2. Quick Start ​

2.1 Large Model Interactive Experience ​

NOTE

The WonderMind Module enables rapid hands-on exploration of diverse voice and vision AI capabilities. See 4. Software and Hardware Guide / 4.4 WonderMind Module for complete documentation.

2.1.1 Powering On ​

  1. Toggle the rear power switch. The screen illuminates, indicating successful startup.
  1. Upon power-up, the device hotspot name and browser configuration URL are displayed, with accompanying voice prompts. Complete 2.1.2 Module Network Setup before proceeding.

2.1.2 Module Network Setup ​

  1. Network setup begins automatically after power-up. The device hotspot name and browser configuration URL are displayed on the screen, with accompanying voice prompts. The WonderMind Module activates its built-in hotspot for connection and configuration. Hotspot names vary by device, following the unified format WonderMind-xxxx. WonderMind-7885 serves as the example.
  1. Locate and connect to the corresponding hotspot via computer or mobile device. No password is required.
  1. Click Network Configuration to access the device network configuration URL directly. Alternatively, copy the URL below and open it in a browser.
py
http://192.168.4.1
  1. Enter the hotspot name for automatic connection on power-up in field ①. Enter the hotspot password in field ②. Finally, click in field ③ Connect. The module attempts to locate and connect to the matching hotspot using the configured credentials.
  1. Available hotspots detected by the module are listed in the interface. Click an entry to auto-populate the corresponding hotspot name in field ①.
  1. If the following prompt appears on the interface, the hotspot is not detected or the password is incorrect. Re-enter the credentials.
  1. If the following prompt appears on the interface, the module has located and connected to the hotspot. The module restarts and reconnects.

NOTE

  • Do not enter hotspots that are undetected, weak, or lack internet access.
  • If a previous hotspot was saved, new credentials are stored alongside existing entries. On the next power-up, the module sequentially attempts each saved entry until a match is found.
  • If the following prompt is displayed after network configuration, Error: New version check failed. Retrying in xx seconds, the hotspot lacks internet access or has unstable connectivity. Switch to an alternative hotspot.

(1) XiaoZhi AI Platform Account Login ​

  1. Click XiaoZhi AI Chatbot to directly access the device binding URL. Alternatively, copy the URL below and open it in any browser.

2.1.4 Device Binding ​

  1. After completing XiaoZhi AI Platform registration, login, and authentication, click Agents to access the interface.
  1. Click the dropdown arrow next to the Add Device button, then click Create Agent.
  1. Enter the agent name, then click Confirm to complete agent creation.
  1. Click Configure to access agent function settings.
  1. Click Role to configure the agent role. Select the desired conversation language in field ①, the desired voice in field ②, and configure voice settings in field ③.
  1. Click Model & Memory. Select DeepSeek V4 (Rich Personality) for the language model. Disable the memory function. Keep other settings as default.
  1. Click Extensions. Enable all official service functions. Keep other settings as default, then click Save.
  1. Click Devices to access device management.
  1. Click Link new device. Enter the 6-digit device ID in the pop-up window, then click Link.
  1. If binding is successful, Device added successfully is displayed. Select Open Source, then click Start Using.
  1. After successful binding, the module enters the MCP setup waiting interface. The current mode waits for an external controller to configure MCP for the large model. Since no external controller is connected, short-press Button A to enter the large model expression mode.
  1. Upon entering the large model expression mode, the module displays expressions. Network configuration and binding are now complete.
  1. Short-press Button B to switch modes. The modes are described below:

  

​ Expression Mode: Supports normal conversation. Dialogue messages are not displayed.

  

​ Image Transmission Mode: Normal conversation is not supported. Dialogue messages are not displayed.

  

​ Chat Mode: Supports normal conversation. Dialogue messages are displayed on the screen. Image recognition is supported.

2.1.5 Free Chat ​

After the module preparation steps are completed, press Button B twice to switch to chat mode. In chat mode, the module is activated by saying the wake word Hello Hiwonder or short-pressing Button A.

The module has built-in special functions that can be activated by voice commands during human-robot interaction. Refer to the following phrases to query all currently supported special functions:

① What can it do? ② Introduce functions.

  

Refer to the following phrases to activate corresponding special functions on the WonderMind Module:

  

  1. Weather Query: Check the weather in location.

  

  1. News Broadcast: ① Broadcast today's news. ② Introduce today's hot events.

  

  1. Outfit Recommendation: Give an outfit recommendation for today.

  

  1. Joke Telling: ① Tell a joke. ② Tell a joke to lighten the mood.

  

  1. Horoscope Query: Check today's horoscope for zodiac sign.

  

  1. Music Playback: Play a random song.

NOTE

Lower the module volume before using music playback.

2.2 Controller Power On and Charging Instructions ​

2.2.1 Powering On ​

Toggle the power switch. The power indicator on the controller illuminates, indicating successful startup.

2.2.2 Charging ​

  1. Ensure the controller switch is set to OFF. Connect the Type-C cable to the controller charging port and to the charger.
  1. The indicator displays the current charging status. All four white LEDs illuminate when fully charged. Disconnect the cable promptly after charging to avoid overcharging.

NOTE

The power switch must be OFF during charging. Otherwise, the battery may not fully charge. Disconnect the charger and cable promptly after charging to prevent battery damage from overcharging.

2.4 Starter Projects ​

2.4.1 Buzzer Alarm ​

(1) Learning Objectives ​

  • Knowledge Objectives: Understand basic operations of the WonderLab programming platform. Learn the function of the buzzer module on the AiBlock controller, sound generation principles, and parameters for volume, pitch, and beat. Master basic programming logic for main loops and button event triggers.

  • Skill Objectives: Complete basic operations for creating new projects and adding controller extensions in the programming software. Independently build graphical programs for buzzer sound generation and volume adjustment. Master the complete workflow of program connection, upload, and debugging.

  • Literacy Objectives: Develop preliminary programming thinking for hardware-software integration. Understand the function of event trigger mechanisms. Build foundational program debugging and hands-on implementation skills.

(2) Adding Extensions ​

  • Open the programming software and create a new project.
  • Click the extensions button in the lower-left corner.
  • Select AI Blocks Board under the Controller category.

(3) Core Blocks ​

BlockCategoryDescription
Program main loop container. Continuously executes internal code after power-on initialization completes.
Drives the buzzer to play notes at specified pitch and beat. Runs in background mode without blocking subsequent program execution.
Adjusts buzzer output volume. Value range 0 to 100. Higher values produce greater volume.
Event-triggered block. Executes internally nested code when a corresponding button short-press is detected.

(4) Program Description and Upload ​

  • Complete Program

    After power-on, the main loop runs continuously with non-stop prompt sound effects. The buttons use event-triggered mechanisms. Short-pressing the left and right buttons modifies the buzzer volume in real time, demonstrating dynamic parameter adjustment for output modules.

NOTE

The source files are available for download under Program Files.

  • Program Upload

    Click Connect device, select the serial port, then click the upload button to complete the program transfer and test the execution results.

2.4.2 Ultrasonic Distance-Based Motor Control ​

(1) Learning Objectives ​

  • Knowledge Objectives: Understand the ultrasonic sensor ranging principle and data parameter meanings. Recognize the operating characteristics of the 360° block motor and 180° block servo. Master the foundational programming logic for distance judgment, sensor data reading, and actuator on / off control.
  • Skill Objectives: Master standard wiring methods for the ultrasonic sensor with motors and servos. Independently add corresponding function extension modules. Proficiently build conditional judgment programs linking distance detection with power output. Complete program upload and function debugging.
  • Literacy Objectives: Establish closed-loop programming thinking of "environmental ranging perception, intelligent judgment, power execution." Develop logical analysis capabilities and hands-on STEAM practice for automatic device control based on environmental data.

(2) Hardware Wiring ​

  • Connect the 360° block motor to port S1 of the controller using a 3-pin servo cable.
  • Connect the 180° block servo to port S2 of the controller using a 3-pin servo cable.
  • Connect the ultrasonic sensor to port A of the controller using a 4-pin module cable.

(3) Adding Extensions ​

  • Select Ultrasonic sensor under the Input Module category.
  • Select 180° servo and 360° Motor under the Motion module category.

(4) Core Blocks ​

BlockCategoryDescription
Initialize the ultrasonic sensor hardware interface.
Retrieve obstacle distance data measured by the ultrasonic sensor. Unit: centimeters, cm.
Control the 360° block motor on the specified port with a custom speed. Select forward or reverse rotation direction for continuous operation.
Cut off output to the 360° block motor on the specified port, stopping rotation immediately.
Control the 180° block servo on the specified port, rotating at a custom speed for a specified duration. Select no-delay mode to continue executing subsequent blocks without waiting for the servo movement to complete.

(5) Program Description and Upload ​

  • Complete Program

    At startup, the ultrasonic sensor hardware interface is initialized to port A, and the servo initial position is set to 0°. The main program loop continuously detects the distance to objects ahead. If the distance exceeds 15 cm, motor S1 maintains forward rotation at 50% speed. Otherwise, the motor stops, and servo S2 rotates to 180° at 50% speed.

NOTE

The source files are available for download under Program Files.

  • Program Upload

    Click Connect device, select the serial port, then click the upload button to complete the program transfer and test the execution results.

2.4.3 Light-Responsive Temperature and Humidity Display ​

(1) Learning Objectives ​

  • Knowledge Objectives: Recognize the detection principles and value ranges of the light sensor and temperature-humidity sensor. Understand the output characteristics of the RGB light module and dot matrix display. Master programming logic for multi-environmental data detection, conditional judgment, visual display, and light linkage.
  • Skill Objectives: Complete wiring and extension addition for environmental sensors with display and light modules. Independently build multi-environmental data collection and intelligent interaction programs. Achieve intelligent control of temperature-humidity display and light states based on light intensity. Advance multi-module collaborative programming and debugging capabilities.
  • Literacy Objectives: Establish advanced programming thinking for multi-sensor environmental perception and multi-output module coordinated feedback. Understand the working principles of intelligent device environmental monitoring and state interaction. Develop data thinking and intelligent scenario innovation application capabilities.

(2) Hardware Wiring ​

  • Connect the light sensor to port A of the controller using a 4-pin module cable.
  • Connect the temperature-humidity sensor to port B of the controller using a 4-pin module cable.
  • Connect the RGB light module to port C of the controller using a 4-pin module cable.
  • Connect the dot matrix module to port D of the controller using a 4-pin module cable.

(3) Adding Extensions ​

  • Select Light sensor and Temperature humidity sensor under the Input Module category.

  • Select Dot matrix module and RGB module under the Output module category.

(4) Core Blocks ​

BlockCategoryDescription
Initialize the temperature-humidity sensor hardware interface.
Read temperature or humidity values in real time.
Read light intensity value from the light sensor on the specified port. Value range 0 to 100. Brighter light produces higher values.
Control the dot matrix display on the specified port. Output specified text at coordinates (x, y). Select scroll or non-scroll mode. Refreshes screen content after execution.
Control the RGB light module on the specified port. Select a preset color to illuminate the light.
Turn off the RGB light module on the specified port. Cut off light output.

(5) Program Description and Upload ​

  • Complete Program

    At startup, the temperature-humidity sensor hardware interface is initialized. The main program loop continuously monitors ambient light intensity. If the light value exceeds 70, the temperature value is displayed in real time on the dot matrix screen, and the RGB light is turned off. Otherwise, the humidity value is displayed in real time on the dot matrix screen, and the RGB light illuminates white.

NOTE

The source files are available for download under Program Files.

  • Program Upload

Click Connect device, select the serial port, then click the upload button to complete the program transfer and test the execution results.
