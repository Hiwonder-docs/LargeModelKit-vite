### 2.1.2 **Module Network Setup**

1. Network setup begins automatically after power-up. The **device hotspot name** and **browser configuration URL** are displayed on the screen, with accompanying voice prompts. The WonderMind Module activates its built-in hotspot for connection and configuration. Hotspot names vary by device, following the unified format **WonderMind-xxxx**. WonderMind-7885 serves as the example.

<img src="../_static/media/chapter_4/section_4/subsection_2/2.png"  class="common_img" style="width:300px;" >

2. Locate and connect to the corresponding hotspot via computer or mobile device. No password is required.

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/1.png"  class="common_img" style="width:400px;" >

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/2.png"  class="common_img" style="width:400px;" >

3. Click [Network Configuration](http://192.168.4.1/) to access the device network configuration URL directly. Alternatively, copy the URL below and open it in a browser.

```py
http://192.168.4.1
```

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/3.png"  class="common_img" style="width:500px;" >

4. Enter the hotspot name for automatic connection on power-up in field ①. Enter the hotspot password in field ②. Finally, click in field ③ **Connect**. The module attempts to locate and connect to the matching hotspot using the configured credentials.

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/4.png"  class="common_img" style="width:500px;" >

5. Available hotspots detected by the module are listed in the interface. Click an entry to auto-populate the corresponding hotspot name in field ①.

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/5.png"  class="common_img" style="width:500px;" >

6. If the following prompt appears on the interface, the hotspot is not detected or the password is incorrect. Re-enter the credentials.

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/6.png"  class="common_img" style="width:500px;" >

7. If the following prompt appears on the interface, the module has located and connected to the hotspot. The module restarts and reconnects.

<img src="../_static/media/chapter_4/section_4/subsection_3/sub_1/7.png"  class="common_img" style="width:500px;" >

> [!NOTE]
>
> * **Do not enter hotspots that are undetected, weak, or lack internet access.**
>* **If a previous hotspot was saved, new credentials are stored alongside existing entries. On the next power-up, the module sequentially attempts each saved entry until a match is found.**
> * **If the following prompt is displayed after network configuration, Error: New version check failed. Retrying in xx seconds, the hotspot lacks internet access or has unstable connectivity. Switch to an alternative hotspot.**

1. Ensure the controller switch is set to **OFF**. Connect the Type-C cable to the controller charging port and to the charger.

<img src="../_static/media/chapter_2/section_1/2.png"  class="common_img" style="width:400px;" >

>
> **The power switch must be OFF during charging. Otherwise, the battery may not fully charge. Disconnect the charger and cable promptly after charging to prevent battery damage from overcharging.**

#### (5) Program Description and Upload

- Complete Program

  At startup, the temperature-humidity sensor hardware interface is initialized. The main program loop continuously monitors ambient light intensity. If the light value exceeds 70, the temperature value is displayed in real time on the dot matrix screen, and the RGB light is turned off. Otherwise, the humidity value is displayed in real time on the dot matrix screen, and the RGB light illuminates white.
